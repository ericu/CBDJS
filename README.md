# CBDJS
This is a <a href="./cb.html">simple tool for designing end-grain cutting boards</a>, a tribute to [and expansion of] <a
href="https://www.lastalias.com/cbdesigner/">CBdesigner</a>.
There's <a href="https://mushymiddle.github.io/CBDJS/cb.html">a fork</a> that adds the ability to save a list of woods to localStorage.
